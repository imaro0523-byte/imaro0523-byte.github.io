자리배치 도우미

나이스에서 내려받은 명렬표 엑셀을 그대로 올리면, 교실 자리 배치·2인 짝꿍·모둠 편성을 만들어 줍니다. 설치할 것도 가입할 것도 없습니다.

앱 열기

무료 · 회원가입 없음 · 설치 없음

학생 정보는 이 컴퓨터를 벗어나지 않습니다.

엑셀 읽기·자리 계산·이미지 저장이 전부 선생님의 브라우저 안에서 끝납니다. 서버도 데이터베이스도 없습니다. 이건 약속이 아니라 앱의 보안 정책으로 막아 둔 것이고, 실제로 측정한 감사 기록도 함께 공개합니다.

이 소개 페이지에는 광고가 있을 수 있습니다. 앱 화면에는 광고가 없으며, 광고 스크립트가 학생 명단이 있는 화면에 들어가지 않도록 페이지를 분리해 두었습니다.

무엇을 할 수 있나요

  • 나이스 엑셀 그대로 — 파일을 고칠 필요 없이 올리면 알아서 읽습니다
  • 모둠 편성 — 25명을 6모둠으로 나누면 5·4·4·4·4·4 처럼 균등하게
  • 모둠 자리 배치 — 모둠마다 책상 섬을 만들고 사이를 통로로 비웁니다
  • 지난 짝·지난 모둠원 피하기 — 기록해 두면 다음 배치에서 참고합니다
  • 전출·자퇴·결석 제외 — 명단에서 지우지 않고 배치에서만 뺍니다
  • 교사 관점 ↔ 학생 관점 — 교탁에서 본 모습과 학생이 보는 모습 전환
  • 공개 모드 — 프로젝터로 이름을 가렸다가 한 명씩 공개
  • 내보내기 — PNG · PDF · 엑셀 · JSON · 인쇄

쓰는 순서

  1. 명렬표 불러오기 — 나이스 «교과시간별출석부»를 그대로 올립니다
  2. 학생 명단 — 전출·자퇴 학생을 «배치 제외»로 바꿉니다
  3. 교실 만들기 — 모둠 수만 고르면 책상 섬이 자동으로 만들어집니다
  4. 조건 정하기 — 없어도 됩니다. 필요한 것만 고르세요
  5. 자리 만들기 — 몇 초면 끝납니다
  6. 결과 보기 — 자리를 바꾸거나 공개 모드로 보여 주고, 저장합니다

자주 묻는 것

제 학교 명렬표도 읽나요?

고정된 셀 위치를 가정하지 않고 «번호»와 «성명» 글자를 찾아 표를 인식하므로, 학교마다 조금씩 다른 양식도 대부분 읽습니다. 자동 인식이 안 되면 헤더 줄과 열을 직접 고르는 화면으로 넘어갑니다.

학생 이름이 서버에 올라가나요?

아니요. 이 도구에는 서버가 없습니다. 브라우저에서 F12 → Network 를 켜고 써 보시면 앱 파일 외에 아무 요청도 없는 것을 직접 확인하실 수 있습니다. 인터넷을 끊고도 그대로 동작합니다.

닫으면 명단이 사라지나요?

네, 기본값이 그렇습니다. 여러 선생님이 함께 쓰는 교무실 컴퓨터를 생각한 설정입니다. 설정에서 «이 브라우저에 저장»을 켜면 남길 수 있고, «모든 정보 삭제»로 한 번에 지울 수도 있습니다.

남녀를 섞어 앉히고 싶은데 성별 열이 없어요

명렬표는 보통 한 무리를 가나다순으로 적고 다음 무리를 다시 가나다순으로 적습니다. 그 순서가 되돌아가는 지점을 찾아 버튼 한 번으로 두 무리로 나눠 줍니다. 어느 쪽이 남학생인지는 알 수 없으므로 «구분1·구분2»로만 표시하고, 서로 바꾸기도 한 번에 됩니다.

안 되는 부분이 있으면

앱 오른쪽 위 «의견 보내기»를 눌러 주세요. 어느 화면에서 무엇을 하려다 그랬는지 알려 주시면 큰 도움이 됩니다.

화면 사진을 보내실 때

그냥 캡처하면 학생 이름이 그대로 찍힙니다. «의견 보내기» 안의 «이름 가린 화면 저장»을 쓰시면 배치 모양은 그대로 두고 이름만 학생01·학생02로 바꾼 그림을 만들어 드립니다. 그 파일을 첨부해 주세요.
