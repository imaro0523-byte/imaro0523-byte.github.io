# 자리배치 도우미 (Seat Planner)

나이스에서 내려받은 명렬표 엑셀로 교실 자리 배치, 2인 짝꿍, 모둠 편성을 만드는 웹 도구입니다.

**학생 이름과 개인정보는 브라우저 밖으로 나가지 않습니다.** 서버도 데이터베이스도 없고,
엑셀 읽기·자리 계산·이미지 생성·파일 저장이 모두 사용자의 컴퓨터 안에서 끝납니다.
자세한 내용은 [PRIVACY.md](PRIVACY.md)를 읽어 주세요.

---

## 무엇을 할 수 있나

- **나이스 엑셀 자동 인식** — 파일을 고칠 필요 없이 그대로 올리면 됩니다. 고정된 셀 위치를
  가정하지 않으므로 학교마다 조금씩 다른 양식도 읽습니다.
- **자리 배치** — 무작위, 출석번호순, 이름순, 지난 짝·지난 옆자리 회피, 고정석, 시험 간격
- **2인 짝꿍** — 홀수 학급이면 «혼자 앉기 / 3인 책상 / 직접 지정» 중에서 고를 수 있습니다
- **모둠 편성** — 모둠 수로 정하거나 모둠당 인원으로 정하고, 나누어떨어지지 않으면
  가능한 대안을 근거와 함께 보여 줍니다 (25명 4인 모둠 → 6모둠 5·4·4·4·4·4 등)
- **모둠 자리 배치** — 교실을 미리 만들 필요 없이, 모둠마다 책상 섬을 자동으로 만들어
  줍니다. 같은 모둠은 마주 보고 모여 앉고 다른 모둠과는 통로를 두고 떨어집니다.
  섬 좌석 수가 모둠 인원과 정확히 같아 빈 책상이 생기지 않습니다.
- **자퇴·전출·결석 학생 제외** — 명단에서 지우지 않고 배치에서만 빼며, 모둠 인원이 자동으로
  다시 계산됩니다. 오늘 결석한 학생은 돌아왔을 때 원래 자리로 복귀합니다.
- **구분 자동 나누기** — 명렬표는 한 무리를 가나다순으로 적고 다음 무리를 다시 가나다순으로
  적기 때문에, 이름 순서가 되돌아가는 지점을 찾아 버튼 한 번으로 두 무리를 나눕니다.
  25명치 드롭다운을 일일이 누를 필요가 없습니다. 어느 쪽이 남학생인지는 알 수 없으므로
  **구분1·구분2로만** 표시하며, 서로 바꾸기도 한 번에 됩니다.
- **교사 관점 ↔ 학생 관점** — 교탁에서 바라본 모습과 학생이 앉아서 보는 모습을 한 번에 전환
- **공개 모드** — 프로젝터로 이름을 가렸다가 한 명씩·무작위로·카운트다운 후 공개
- **내보내기** — PNG · JPG · PDF · Excel · JSON · 인쇄
- **오프라인 사용** — 설정에서 켜면 인터넷 없이도 동작합니다 (기본값은 꺼짐)

## 설치와 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
```

개발 서버:

```bash
npm run dev
```

`http://localhost:5173` 에서 열립니다.

프로덕션 빌드:

```bash
npm run build
```

빌드 결과를 미리 보기:

```bash
npm run preview
```

## 내 명렬표가 인식되는지 확인하기

파일을 앱에 올려 보는 것이 가장 빠르지만, 명령줄에서도 확인할 수 있습니다.
**학생 이름은 출력되지 않고 글자 수만 표시**되므로 결과를 그대로 공유해도 안전합니다.

```bash
npm run inspect -- "C:/경로/1-1반 명렬표.xlsx"
```

## 정적 호스팅으로 배포하기

빌드 결과(`dist/`)는 순수한 정적 파일이라 어디에나 올릴 수 있습니다.

### GitHub Pages

이 저장소에는 `.github/workflows/deploy.yml` 이 들어 있습니다.

1. GitHub에 저장소를 만들고 코드를 올립니다.
2. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
3. `main` 브랜치에 push하면 자동으로 빌드되어 `https://<사용자>.github.io/<저장소>/` 에 배포됩니다.

`vite.config.ts` 의 `base: './'` 덕분에 하위 경로에 배포해도 그대로 동작합니다.

### 그 밖의 방법

`dist/` 폴더를 웹 서버에 복사하기만 하면 됩니다. 별도의 설정이나 백엔드가 필요 없습니다.

> **배포해도 개인정보는 안전한가?**
> 네. 서버는 HTML·CSS·JS 파일을 내려 줄 뿐이고, 교사가 올린 엑셀은 브라우저 밖으로 나가지
> 않습니다. 서버 운영자도 학생 명단을 볼 수 없습니다.
>
> 이것은 감사에서 **실제로 측정**한 결과입니다. 17개 유출 경로에 표식을 실어 쏘아 본 뒤
> 무엇이 차단되고 무엇이 통과하는지 확인했고, 남은 한 가지 한계까지
> [SECURITY_AUDIT.md](SECURITY_AUDIT.md)에 적어 두었습니다.

## 알려진 제한사항

- **PDF의 제목 줄은 한글이 깨질 수 있습니다.** 자리 배치도 자체는 이미지로 넣기 때문에 한글이
  정상 출력되지만, jsPDF 기본 글꼴에는 한글이 없어 여백의 부제목은 영문·숫자만 안전합니다.
  한글 글꼴을 포함하면 파일이 수 MB 커지므로 넣지 않았습니다.
- **Firefox에서는 삭제 확인이 부분적입니다.** `indexedDB.databases()` 를 지원하지 않아
  삭제 자체는 정상 수행되지만 «남은 것이 없음»을 자동으로 재확인하지 못합니다.
- **엑셀 암호 해제는 지원하지 않습니다.** 암호가 걸린 파일은 엑셀에서 먼저 암호를 푼 뒤
  올려 주세요.
- **업로드 파일에 상한이 있습니다.** 20MB · 시트당 20,000행 · 512열 · 100시트.
  명렬표는 보통 10KB 남짓이라 실제로 걸릴 일은 없습니다.
- **GitHub Pages에 올리면 다른 사이트가 이 앱을 iframe으로 감쌀 수 있습니다.**
  `frame-ancestors`가 meta 태그에서 무시되고 GitHub Pages는 응답 헤더를 보낼 수 없기
  때문입니다. 헤더를 보낼 수 있는 호스트(Netlify·Cloudflare Pages)에 올리면
  `public/_headers`가 자동 적용되어 막힙니다.
- **개인정보 검증은 Chromium에서만 측정했습니다.** Firefox·Safari 동작은 미확인입니다.
- **아주 큰 명렬표**(수백 명)는 «정밀 생성»에서 몇 초가 걸릴 수 있습니다. 계산은 Web Worker에서
  돌기 때문에 화면이 멈추지는 않습니다.
- **모둠별 책상 템플릿**(ㄷ자형·원형 등)은 아직 격자 기반 배치만 제공하며, 완전한 자유 배치는
  넣지 않았습니다.
- **내보낸 파일에는 암호가 걸리지 않습니다.** 학생 이름이 들어 있으므로 저장 위치는 사용자가
  직접 관리해야 합니다.
